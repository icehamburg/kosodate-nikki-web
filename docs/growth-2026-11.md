## 計測リンクの決めごと

形式: `https://apps.apple.com/app/apple-store/id6758967429?pt=<プロバイダトークン>&ct=<キャンペーン>&mt=8`

- **pt（プロバイダトークン）は ASC でしか発行できず、まだ手元にない**。コードは pt を1か所の定数にまとめ、空なら今までどおりの素のURLにする（壊れない）。pt を受け取ったら、その定数を埋めるだけで計測が始まる
- ct の割り当て（ASCの「キャンペーン」別に数字が見える）

| ct | 置き場所 |
|---|---|
| `lp` | LP（kosodate-nikki.jp）の全ダウンロードボタン |
| `invite` | アプリの夫婦共有「招待を送る」 |
| `column` | アプリのコラム共有 |
| `kt-fuyo` / `kt-kingaku` / `kt-hoiku` / `kt-shussan` | kodomo-teate の 児童扶養手当 / 児童手当の金額 / 保育園の申込み / 出産チェックリスト |
