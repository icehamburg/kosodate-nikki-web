# LPイラスト制作ブリーフ(2026-08)

ChatGPT(GPT-4o画像生成)で作り、`public/illustrations/` に置く。
配置のコード修正は、ファイルが揃ったタイミングで Claude Code / Codex に依頼する。

## 全体方針

- ヒーローは引き続き**スクリーンショットが主役**(「話すだけ」の証拠)。イラストは
  感情を伝えるセクション(安心・CTA・成長グラフ)に絞って足す。1セクション1主役を守る
- LPの既存パレットに合わせる。**イラスト側で新しい色を増やさない**
- 全カットで**同じ家族(親2人+赤ちゃん1人)**を使う。ChatGPTの**同じ会話の中で連続生成**
  すると人物の一貫性が保ちやすい

## 共通スタイル(全プロンプトの先頭に貼る)

```
やわらかいフラットイラスト。輪郭線なし、面の塗りだけで構成。形はすべて丸みを帯びている。
紙のようなごく軽いテクスチャ。文字・ロゴは一切入れない。背景は透過(transparent PNG)。
使う色はこの5色だけ: テラコッタ#D97757 / アプリコット#FFB088 / クリーム#F5F0EA /
ダークブラウン#3C3A37 / 白。
日本の絵本のような、静かで温かい雰囲気。かわいすぎない。ベビーポップにしない。
登場人物は、短髪の親・髪を結んだ親・赤ちゃんの3人家族。顔は点の目と小さな口だけのシンプルな表現。
```

## 各カットのプロンプト(共通スタイルに続けて貼る)

### 1. anshin-check.png — 保存前に確認できます
```
スマホの吹き出しの中に、やさしいチェックマーク。その横で、短髪の親が指で画面を
そっと確認している手元のクローズアップ。「AIの出した内容を人が確かめる」瞬間を、
穏やかに描く。要素は吹き出し・チェック・手だけ。余白を大きく。
```

### 2. anshin-family.png — データはご本人と家族のもの
```
小さな丸い家の形の中に、3人家族が寄り添っているシルエット気味の構図。
家のまわりにはなにもなく、守られている静けさを感じる。鍵や錠前は使わない
(セキュリティ感ではなく「家族の中だけ」という温度で)。
```

### 3. anshin-noad.png — 広告はありません
```
夜、布団で眠る赤ちゃんと、その横に置かれた静かなスマホ。画面には何も表示されて
いない(真っさらなクリーム色)。三日月をひとつ。騒がしいものが何もない、
静けさそのものを描く。
```

### 4. cta-night.png — 今日から、話すだけで
```
夜のリビングで、髪を結んだ親が赤ちゃんを抱きながら、口元に小さな音符がひとつ
浮かんでいる(話しかけている)。窓の外に三日月。横長の構図で、左右に大きく余白。
白い要素を主体に(濃い色の背景の上に置くため)。
```

### 5. growth.png — この子のペースの成長カーブ
```
左下から右上へ、ゆるやかにのぼる1本の曲線。線の上を、ハイハイの赤ちゃんが
のぼっていく。曲線の先に小さな芽(ふたば)。目盛り・数字・グリッド線は絶対に
入れない(「比べない」ことがテーマ)。曲線はテラコッタ、余白たっぷり。
```

### 6. hero.png — 話すだけで、記録になる。(任意)
```
ソファで赤ちゃんを抱いた短髪の親が、少し先に置いたスマホに向かって話しかけている。
スマホからは丸い波紋がふわっと広がり、その中にミルク瓶と月のアイコンが浮かんでいる
(声が記録に変わる瞬間)。縦長の構図。
```

## 受け入れチェック(生成後に確認)

- [ ] 背景が透過になっているか(白背景で書き出されがち。「背景透過で」と念押しする)
- [ ] 5色以外の色が混ざっていないか(特に肌色・水色が勝手に入りやすい)
- [ ] 文字・数字が紛れ込んでいないか
- [ ] 3人家族の見た目がカット間でブレていないか
- [ ] 1024px以上あるか(Retina表示で使うため)

## 配置時のメモ(実装担当向け)

- 安心セクション: 各 `reassure-item` の番号サークルの上に 96〜120px で置く
- CTA: 見出しの上に幅 280〜360px。背景がグラデーションなので白主体のカットを使う
- growth: `page.tsx` のコメントアウト済みセクション(`id="growth"`)の `Image` が
  すでに `/illustrations/growth.png` を参照している。v2.4.0公開確認後にコメントを外す
- hero差し替えは効果が読めないので、まず4カット(1〜3, 5)を入れてから判断する
