# ASO改善案（2026-08-24策定）

前提知識: **iOSの検索インデックスはApp名(30字)+サブタイトル(30字)+キーワード欄(100字)の160字のみ**。
説明文・プロモーションテキストは検索順位に一切効かない（読んだ人の転換にのみ効く）。
フィールド間で語を重複させない（重複は順位に効かず枠の無駄）。
Appleがフィールド横断でトークンを自動組み合わせるので複合語は書かなくてよい。

背景データ: ASC獲得ソースは「App Storeの検索」が実質すべて（日次平均2、参照元Web/アプリは平均0）。
`子育て` と `育児` は別トークンで、現状は `育児` を一切持っていない（まとめ記事・競合の主要語は「育児記録」）。

## 適用する値

### App名（22字/30字）※審査つき・バージョン単位
```
子育て記録日記 - 話すだけの育児・授乳記録
```

### サブタイトル（21字/30字）※審査つき・バージョン単位
```
ミルク・睡眠・成長を声で残して、夫婦で共有
```
（現行「毎日のこども記録を行えるアプリです」は「行えるアプリです」8字が死に領域）

### キーワード欄（96字/100字）※審査つき・バージョン単位
```
母乳,離乳食,おむつ,体温,身長,体重,発育,月齢,赤ちゃん,ベビー,新生児,乳児,幼児,ママ,パパ,AppleWatch,ウォッチ,音声入力,無料,かんたん,写真,タイマー,寝かしつけ,生後
```
原則: スペース不使用 / 名前・サブタイトルと重複させない / 持っていない機能の語（予防接種・妊娠等）は入れない。

### プロモーションテキスト（105字/170字）※審査なし・即時反映可
```
深夜の授乳中でも、抱っこで両手がふさがっていても。「ミルク140飲んで、さっき寝たよ」と話すだけで記録になります。身長・体重の成長グラフも加わりました。夫婦で共有でき、Apple Watchからも記録できます。
```

## 適用タイミング

- プロモーションテキスト: **いつでも可**（v2.4.0公開を待たず反映してよい）
- 名前・サブタイトル・キーワード: 審査中は編集不可。**v2.4.0承認後、次の提出（v2.4.1）に載せる**
- 主カテゴリ: ライフスタイル → **メディカル** へ変更（競合はメディカルで52位・57位でもチャート掲載。
  ライフスタイルはみてねが35位の激戦区）。ASC設定のみ・次バージョン反映
